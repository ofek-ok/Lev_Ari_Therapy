# Lev Ari Therapy – Activity & Operations Dashboard

A bilingual (Hebrew RTL / English LTR) web-based activity & operations management platform built for **Lev Ari Therapy** and managed by **Ofek (Okonski Performance)**.

## Quick Start

```powershell
cd C:\Users\ofekok\.gemini\antigravity\scratch\lev-ari-dashboard
npm start
```

Then open **http://localhost:3456** in your browser.

## Excel Workbook Source-of-Truth Mapping

| Worksheet # | Excel Sheet Name | Imported Records | Application Section |
| :--- | :--- | :--- | :--- |
| **1** | `Task Tracker` | 12 Tasks (`P1`–`P7`) + 2 Operating Framework rows (`Weekly capacity`, `Working principle`) | **Overview Dashboard** & **Task Management** |
| **2** | `Massage Schools` | 10 Researched Institutions with Hebrew outreach drafts + 11 `Already contacted` (Do Not Duplicate) + 3 `Existing relationship` + 1 Verification Policy banner (`הערת אימות`) | **School Outreach** |
| **3** | `Athletic Groups` | 30 Structured Group Slots (`#1–10` Running, `#11–20` Cycling, `#21–30` Triathlon) | **Athletic Groups** |
| **4** | `Social Media Log` | 8-Column Structured Schema (`Platform / Page`, `Post / Topic`, `Action`, `Personal Comment / Caption Draft`, `Post URL`, `Audience / Groups Reached`, `Result / Engagement`, `Follow-up`) | **Social Media Activity** |
| **5** | `Meetings & Decisions` | 8-Column Structured Schema + Chronological Milestones | **Activity & Meetings Log** |
